## Templates

Copy these folders to your Kicad 10 templates dir. This can be found by opening Kicad, selecting
`Preferences > Configure Paths...` and looking at the value of the `KICAD_USER_TEMPLATE_DIR` field.

On MacOS, the default is `~/Documents/KiCad/10.0/template/`.

```bash
# MacOS:
cp -R templates/ $HOME/Documents/KiCad/10.0/template/

# Linux:
cp -R templates/ $HOME/.local/share/kicad/10.0/template/
```
